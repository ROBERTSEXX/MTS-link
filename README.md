# Скачивание записей МТС Линк

## Пакетная загрузка по списку ссылок (`mtslink-dl`)

`mtslink-dl` скачивает сразу много записей: ссылки передаются аргументами или
файлом (по одной в строке). Для каждой ссылки по очереди пробуются все способы,
пока один не сработает, а ошибка одной записи не останавливает остальные.

| Способ    | Что делает |
| --------- | ---------- |
| `direct`  | ссылка уже ведёт на `.mp4`/`.m3u8`/`.mpd` — сохраняется напрямую |
| `api`     | журнал записи берётся из API МТС Линк (`/api/eventsessions/.../record` на `gw`/`my`, `/api/event-sessions/.../record-files/.../flow`), сегменты скачиваются и собираются ffmpeg |
| `browser` | тот же журнал, но через настоящий браузер: работают cookies и вход в аккаунт |
| `sniff`   | страница открывается в браузере, плеер запускается, перехваченный поток сохраняется |
| `ytdlp`   | универсальный загрузчик yt-dlp как последний рубеж |

Каждый сегмент тоже качается с запасными путями: прямой MP4 → HLS → скачивание
байтами с докачкой и локальной перепаковкой. Если в журнале нет привычной
структуры `mediasession`, включается запасной разбор «все `data.url` из событий»
(как в mtslinker/mtser) с проверкой файлов через ffprobe.

### Установка

Нужны Python 3.10+ и `ffmpeg`/`ffprobe` в `PATH`. Ядро работает на стандартной
библиотеке; Playwright и yt-dlp нужны только для своих способов.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[all]"                 # или без [all], если браузер не нужен
python -m playwright install chromium   # для способов browser и sniff
```

Без установки можно запускать `python mtslink_dl.py ...` из корня репозитория.

### Запуск

```bash
mtslink-dl -i links.txt -o downloads
mtslink-dl URL1 URL2 --session-id XXXX         # закрытые записи по cookie sessionId
mtslink-dl -i links.txt --login                # войти в браузере один раз на весь список
mtslink-dl -i links.txt --mode all -j 2        # все источники отдельно, 2 записи параллельно
mtslink-dl -i links.txt --dry-run              # только показать, что найдено
mtslink-dl -i downloads/mtslink-failed.txt     # повторить неудачные
```

Файл со списком — одна ссылка в строке, после неё можно указать имя файла,
строки с `#` — комментарии:

```text
# курс по Python
https://my.mts-link.ru/j/org/123/record-new/456            Лекция 1
https://my.mts-link.ru/12/34/record-new/56/record-file/78 | Лекция 2
Лекция 3: https://my.mts-link.ru/12/34/record-new/90
```

Режимы (`--mode`):

- `auto` (по умолчанию) — один файл `<название> [id].mp4`: сводное видео, если в
  записи были слайды или демонстрация экрана, иначе камера спикера; голоса
  участников подмешиваются в своё время;
- `speaker` — только камера спикера (без перекодирования слайдов);
- `composite` — всегда сводное видео (материалы + спикер в углу);
- `all` — все источники отдельно (`-speaker.mp4`, `-screen-share.mp4`,
  `-audio-<id>.m4a`, `-presentation.pdf`) и основной файл.

Повторный запуск пропускает уже скачанное (`.mtslink-completed.json` в папке
результатов), а прерванная запись продолжается с кэша сегментов
(`.mtslink-work/`). В папке результатов также появляются `mtslink-report.json`
(какой способ сработал, причины ошибок) и `mtslink-failed.txt` для повтора.

### Архитектура

Код в `src/mtslink_downloader` разделён на слои по принципам SOLID:

```text
presentation (CLI) → application (сценарии, политика, порты) → domain (модели, правила)
                              ↑
infrastructure: HTTP, Playwright, ffmpeg, файлы — реализуют порты
bootstrap.py — единственное место, где выбираются реализации
```

- **domain** — модели записи, разбор ссылок, временная шкала сводного видео; без ввода-вывода.
- **application** — `DownloadBatch` (пакет), `FallbackDownloader` (перебор способов),
  `RecordTimelineStrategy` (журнал → модель → план → сборка), `ExportPlanner` (что сохранить),
  узкие протоколы-порты.
- **infrastructure** — источники журнала (API, браузер), парсеры (подробный и запасной),
  загрузка сегментов, обработка ffmpeg, сводное видео, способы `direct`/`sniff`/`ytdlp`,
  список ссылок, каталог и отчёт.

Новый способ скачивания — это класс с `name`, `supports()` и `download()`, добавленный в
`bootstrap.py`; остальной код не меняется. Тесты (`pytest`) включают сквозные проверки на
локальной копии API с медиа, сгенерированным ffmpeg, в том числе браузерные способы.

```bash
pip install -e ".[dev]" && pytest
```

## Одиночная загрузка с выбором потоков (`download_mts_link.py`)

Утилита принимает URL страницы записи МТС Линк, проверяет страницу в браузере, показывает все найденные видео-, аудиопотоки и источники презентаций и предлагает выбрать нужные. Видео сохраняется отдельным MP4-файлом, аудио участника — M4A-файлом, а демонстрация презентации — оригинальным PDF-файлом. Дополнительно можно собрать всю запись в один MP4: материалы идут основным изображением, а спикер — в маленьком окне справа сверху.

### Установка

Нужны Python 3.9+ и `ffmpeg`/`ffprobe` в `PATH`.

На macOS:

```bash
brew install ffmpeg
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install chromium
```

### Запуск

```bash
source venv/bin/activate
python download_mts_link.py \
  "https://my.mts-link.ru/j/something/xxx/record-new/xxx" \
  --output-dir downloads
```

Перед большим скачиванием можно проверить, что страница разобрана корректно:

```bash
python download_mts_link.py "URL_ЗАПИСИ" --dry-run
```

При обычном запуске утилита выведет, например:

```text
1. Спикер / камера
   формат: h264, 1280x720, видео + звук
2. Демонстрация презентации
   формат: PDF / слайды
3. Аудио участника: Имя участника
   формат: aac, только звук
4. Расшаренный экран
   формат: h264, 1920x1056, только видео
A. Все потоки и источники
C. Сводное видео: материалы + спикер в правом верхнем углу
D. Все источники и сводное видео
```

После этого можно ввести `C` для сводного видео, `D` для полного комплекта, `A` для всех отдельных источников или номера через запятую, например `1,2` или `2,3`. По умолчанию отдельные файлы будут созданы в `downloads` с суффиксами `-speaker.mp4`, `-presentation.pdf` и `-screen-share.mp4`. Для презентации каталог также показывает число уникальных слайдов, встречающихся в журнале, и её положение внутри записи.

Для неинтерактивного запуска:

```bash
python download_mts_link.py "URL_ЗАПИСИ" --streams all
python download_mts_link.py "URL_ЗАПИСИ" --streams 2,3
python download_mts_link.py "URL_ЗАПИСИ" --composite
python download_mts_link.py "URL_ЗАПИСИ" --full-package
```

Сводный файл будет сохранён с суффиксом `-combined.mp4`. Скрипт сам использует временную шкалу МТС Линк: сначала оставляет видео спикера, затем показывает слайды, переключается на screen share и возвращает видео спикера в промежутках без демонстрации. Голос берётся из потока спикера, а голоса участников подключаются к нему в своих исходных временных интервалах.

Режим `D`/`--full-package` сначала сохраняет все отдельные MP4/PDF-файлы, а затем создаёт `-combined.mp4` из уже скачанных видеоматериалов. Это удобно, если нужны и исходные источники, и итоговая лекция одним файлом.

Если МТС Линк отдаёт отдельный участок конференции только с аудио, скрипт сохраняет этот звук и добавляет на тот же период чёрный видеоряд. Благодаря этому загрузка не прерывается, а аудиодорожка и общая временная шкала записи не теряются.

Аудиосессии участников распознаются по отдельному `conference.id`. В режиме `A` их можно выбрать по номерам или скачать все источники; отдельные файлы сохраняются с суффиксом `-audio-<id>.m4a`. В режимах `C` и `D` эти файлы автоматически микшируются в сводный MP4 с задержкой, соответствующей их положению в записи.

Для своего общего имени:

```bash
python download_mts_link.py "URL_ЗАПИСИ" -o downloads -f lecture
```

В этом случае будут созданы `lecture-speaker.mp4`, `lecture-presentation.pdf` и `lecture-screen-share.mp4`. Для screen-share сохраняется активная часть потока; каталог показывает её положение внутри исходной записи. Для общего имени сводного файла используется `lecture-combined.mp4`.

Если ссылка требует входа, запустите с `--headed`, выполните вход в открывшемся окне и нажмите Enter в терминале:

```bash
python download_mts_link.py "URL_ЗАПИСИ" --headed
```

Для перезаписи существующего файла добавьте `--overwrite`. Параметр `--verbose` включает подробный журнал.

### Ограничения

- Утилита рассчитана на публичные ссылки МТС Линк формата `/j/.../record-new/...`.
- Нужен установленный `ffmpeg`; он не устанавливается через `pip`.
- Браузер используется для проверки доступности страницы и получения актуального описания записи. Утилита не импортирует cookies из профиля Яндекс Браузера.
- Демонстрация презентации в записи МТС Линк является отдельным набором событий со ссылкой на исходный PDF, а не видеопотоком. Поэтому она скачивается как PDF, без преобразования слайдов в MP4.
